Non-Linear Data Structures & Basics

Trees are non-linear; data branches out instead of sitting in a sequence, drastically speeding up searches.
A tree contains a root node, and remaining nodes partition into disjoint sets (subtrees).

Terminology & Properties

Leaf nodes have no successors. Level = distance from root. Height = total levels. Depth = edges from root.
Binary trees have utmost 2 children. Nodes at level 'L' = 2^L. Total edges 'e' = n - 1.

1.0.0 Array Implementation Theory

0-Indexed Rule: Left child is at 2k+1. Right child is at 2k+2. Parent is at (k-1)/2.
Array representation saves space (no pointers) but is terrible for skewed trees due to massive memory wastage.

else

return 0;
}
